小智 AI 烧录指南（虾哥版）

January 10, 2026 · 3 min read

本文将详细介绍 虾哥小智 AI 的完整烧录流程，适合第一次接触 ESP32 / 小智 AI 的新手，也可作为项目复现与教学文档使用。

一、你将获得什么？​

完成本教程后，你将能够：

  • ✅ 将 **小智 AI 固件成功烧录到 ESP32S3
  • ✅ 在网页端调试和修改 AI Prompt
  • ✅ 让小智 AI 正常联网、对话、响应
  • ✅ 为后续 多智能体 / 哲学角色定制 打好基础

二、硬件与软件准备​

1️⃣ 硬件清单​

  • ESP32 开发板（推荐 ESP32-WROOM 系列）
  • USB 数据线（注意不是只充电线）
  • 稳定的 Wi-Fi 网络
  • 一台电脑（Windows / macOS 均可）

2️⃣ 软件与工具​

请提前准备以下环境：

  • Google Chrome / Edge 浏览器
  • 虾哥小智 AI 官方烧录网页
  • ESP32 USB 驱动（如 CP210x / CH340）

💡 如果电脑无法识别 ESP32 串口，通常是驱动未安装。

三、进入小智 AI 烧录页面​

打开虾哥小智 AI 官方烧录网页：

👉 **https://xiaozhi.me/**（示例地址，请以实际为准）

在首页你可以看到：

  • 固件选择
  • 串口连接
  • 网络配置
  • Prompt / Agent 设置

四、ESP32 连接与烧录步骤​

Step 1：连接开发板​

  1. 使用 USB 线将 ESP32 连接电脑
  2. 点击网页中的 「连接设备 / Connect」
  3. 在弹窗中选择对应的 COM / USB 端口

Step 2：选择固件​

在固件选项中：

  • 选择 最新稳定版小智 AI 固件
  • 如果你是第一次烧录，建议：
    • ❌ 不要选 beta
    • ❌ 不要选自定义分支

Step 3：开始烧录​

  1. 点击 「烧录 / Flash」
  2. 等待进度条完成（约 1–3 分钟）
  3. 看到 Flash Success / 烧录成功 提示

⚠️ 烧录过程中请勿拔线或刷新页面

五、网络配置（非常关键）​

烧录完成后，小智 AI 需要联网才能工作。

配置步骤：​

  • 输入 Wi-Fi 名称（SSID）
  • 输入 Wi-Fi 密码
  • 点击 保存 / Save
  • 等待设备自动重启

📡 当你看到串口日志中出现联网成功信息，说明配置完成。

六、网页端调试与 Prompt 设置​

烧录成功后，你可以在网页端直接控制小智 AI 的行为。

你可以做什么？​

  • ✏️ 修改 AI 的 角色 Prompt
  • 🌐 设置中英文输出
  • 🧠 设定性格、语气、知识边界
  • 🔁 实时调试 AI 响应效果

例如：

你是一个哲学 AI，擅长用通俗语言解释复杂思想。
